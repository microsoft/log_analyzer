# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/log_analyzer/issues) to track bugs and feature
requests. Please search the existing issues before filing a new one to avoid duplicates. For a new issue, file your
bug or feature request as a new Issue and include the information listed in [CONTRIBUTING.md](CONTRIBUTING.md#reporting-issues).

Do not attach unsanitized logs: remove host names, IP addresses, credentials and any other private data first.

For questions about using this project, open an Issue with the `question` label.

To report a security vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
